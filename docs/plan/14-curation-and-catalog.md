# 세션 14 — 검수/승격 + 카탈로그 성숙 [P3]

> **단독 실행 단위.** 새 대화창에서 착수하려면 아래 "부트스트랩"을 먼저 읽어라.

## 시작 전 읽기 (부트스트랩)
- **스펙**: `docs/spec/motif-library-and-multicolor.md` — §8(검수/승격 2단계 게이트), §7.4(풀=curated),
  §6.4(캐시 무효화), 결정 **D5·D14·D18**.
- **현재 코드**: `app/motifs/store.py`(S9 — `status` 컬럼), `app/adapters/motif_resolver.py`(S11 — 변형
  풀), `app/adapters/llm.py`/`recraft.py`(어댑터 캐시 `_intent_cache`/`_motif_cache`).
- **선행 세션**: **S9**(영속화), **S11**(변형 샘플링·풀).

## 목표
**Tier2 사람 검수 → `curated` 승격** 워크플로를 만들고, **curated 풀로 변형 샘플링을 본격화**한다.
head 카탈로그를 시드하고, 행 수가 충분해지면 ivfflat 인덱스를 도입한다.

## 선행 조건
S11(변형 샘플링·풀), S9(영속화).

## 범위
- `status` `auto → curated` 전이 워크플로 + **최소 검수 엔드포인트/도구**(비전 LLM 자동검사는 D14로 보류).
- 샘플링 풀 = **`curated`만**(§7.4) 적용 → **변형 다양성 실효**(여기서부터 풀≥2 가능).
- **head 명세 고퀄 시드**(검수 부담↓).
- **ivfflat 인덱스 도입**(행 수 충분 시, D18) — 소량 구간 seq scan에서 전환.
- **캐시 무효화(§6.4)**: 반려·삭제 시 인메모리 `MOTIFS`/어댑터 캐시/DB 일관성 전파.

## 비범위
비전 LLM 의미검사(D14 보류), 자동 미적 평가, 완전 자동 승격.

## 작업 / 만들·수정 파일
- `app/motifs/store.py`(status 전이, 무효화 전파).
- (신규) 최소 검수 엔드포인트.
- 마이그레이션(ivfflat 인덱스).
- (신규) head 카탈로그 시드 스크립트.

## 수용 기준 (검증 가능)
1. **`curated`만** 샘플링 풀 진입(자동 `auto`는 제외).
2. 풀 ≥ 2에서 **변형 다양성 실효**: 같은 명세 반복 요청이 seed별로 다른 curated 변형.
3. 반려/삭제 모티프가 인메모리/어댑터 캐시/DB에서 **일관 제거**.
4. ivfflat 도입 후 검색 recall 회귀 없음(seq scan 대비 동등 이상).

## 리스크
검수 운영 부하, 캐시 무효화 일관성, ivfflat `lists` 튜닝/소량 recall.

## 종료 조건 (공통)
`pytest` 그린 + 수용 기준 + 작성/검토 분리 verifier.
